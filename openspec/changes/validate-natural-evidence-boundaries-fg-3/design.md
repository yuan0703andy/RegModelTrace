# Design

The execution order is: freeze deterministic discovery procedure; search the six identified PDFs; record all page-level leads and exclusions; audit prior exposure against a frozen file ledger; verify exact source context; mechanically construct and hash gold-blind evidence packets; obtain two independent human judgments on precisely those packets; freeze scorer-only truth; qualify runtime repeatability on exposed synthetic controls; run one predeclared schedule for both checkpoints; persist raw results before scoring; report label and evidence-grounded joint correctness. Model identities are blinded for post-hoc error coding.

Panel A concerns requirement/evidence semantics and uses the existing `SUPPORTED`, `CONTRADICTED`, `CONFLICTING`, `UNRESOLVED` contract. Panel B distinguishes `SCRUTINY_ONLY` from `CHALLENGE_ESTABLISHED` with an explicit not-adjudicable exit. Panel C labels an **explicit documentary statement** linking reviewer intervention to same-object model-method/implementation modification; this is not independent causal proof. The positive label is `EXPLICIT_REVIEW_LINK_STATED`, and disclosure-response changes alone do not satisfy it.

The candidate registry holds discovery provenance and source references, never gold. The evidence packet is constructed before adjudication under the separate frozen packet protocol, retains all first-tier matches, and is immutable and hash-bound to both human adjudication and model inference. A blinded source-scope resolver distinguishes packet omission from source indeterminacy without retrofitting the packet. Scorer-only truth is inaccessible to the runner. Discovery and exposure ledgers preserve rejected and ambiguous candidates so a missing case cannot be mistaken for corpus absence. Host citation resolution checks identity; independent source review checks whether a cited span supports the verdict.

The frozen source discovery produced page leads, so [case formation](../../../experiments/fg3_natural_boundary/protocol/case_formation_protocol.json) is a separate checkpoint before substantive screening. Each lead has a fixed first-match anchor. Panel A searches same-cycle vendor material by exact source identifiers, headings, then recorded literal terms. Panel B uses the whole reviewer comment and attached disposition. Panel C searches the same-cycle counterpart by ordered exact identifiers and object names, preserving all matches at the first nonempty tier. Overflow or ambiguous pairing exits without hand-selecting a convenient passage. Final cases are grouped across repeated clauses, comments, responses, and whole/facet variants; page deduplication is not treated as statistical independence.

No new retrieval architecture, oracle ladder, temporal filtering, fine-tuning, calibration, or active-default switch is part of this change. Those are possible later questions only if FG-3 findings warrant them.

The cue-defined discovery frame is not a census. Its frozen no-hit audit targets four pages per document; only 21 such pages exist under the rule. A `KNOWN_EXPOSURE_LEDGER_V1` file manifest defines operational exposure clearance without opening protected KCC Test E truth. FG-3 tests semantic judgment; FG-4 retrieval eligibility is independent of FG-3 accuracy and requires a separate prospective protocol. Configuration comparisons cannot isolate checkpoint effects from runtime, quantization, or reasoning mode.
