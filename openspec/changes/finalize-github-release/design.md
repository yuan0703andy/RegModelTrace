# Design

## Keep

- core `regmodeltrace` package and service contract;
- final parser, assertion, retrieval, generation, alignment-v2.2, and Ray executor implementations;
- unit tests that run without model weights;
- static product demo and source-bound evidence sample;
- REVIEW-1 reports and machine summaries;
- final KCC, RAG, M3.6, and SCALE-1 reports/receipts needed to substantiate README claims;
- consolidated durable OpenSpec capabilities and this release change.

## Remove

- unrelated soil/water documents and render scratch files;
- raw/duplicate PDFs, model outputs, embedding matrices, SQLite indexes, DCC logs, and transient audit packs;
- superseded M3/M4 prompt iterations, run scripts, SLURM experiments, and completed change specs;
- nested Git metadata, caches, temporary files, and generated archives.

The full research archive is not represented as deleted evidence in the scientific record: the public README will state that large source/result artifacts are omitted and that the included reports are a compact release package.

## Publication

Initialize one clean history from the final release tree, create a public repository under the authenticated GitHub account, push `main`, and verify the remote commit and repository visibility.
