# Design

1. Preserve the current Checkpoint 2 files as historical provisional artifacts. Write repaired results under `experiments/fg3_natural_boundary/checkpoint2_r1/` with an old/new disposition crosswalk; do not overwrite the frozen discovery or the old hit sets.
2. Reconstruct each nonterminal source unit from the fixed anchor and panel-specific natural boundary. Record exact text spans, a printed parent heading and its source ref, boundary start/end evidence, page continuation, and explicit overflow/uncertainty. `anchor_in_unit` is necessary but not sufficient: the next same-level boundary or document end must justify the end span. The known-exposed reviewer page remains a terminal audit entry, not pending primary pairing.
3. Derive every pairing key from exact printed text in the canonical unit or its permitted parent heading. Store key type, normalized identity, source span, and derivation. A bare `V-1` is never sufficient identity: `FORM:V-1`, `STANDARD:V-1`, disclosure/comment/response IDs, and explicit technical names remain distinct. Apply only fixed Unicode dash glyph canonicalization to IDs; no fuzzy or semantic expansion.
4. Record all source-derived keys for each ordered tier before counterpart search. Panel A tier 1 finds the same-cycle vendor section by typed heading, then retains its complete bounded substantive paragraphs. Panel C searches the same-cycle counterpart for exact typed identifiers or later exact source phrases, stopping at the first nonempty tier and retaining every match. TOC, running headers, and copied requirements are preserved as rejected matches with source refs and reasons. Section and paragraph boundaries must be verifiable from adjacent headings; unresolved structural ambiguity exits as `POST_HOC_PAIRING_RULE_REQUIRED`.
5. Recompute overflow only from compliant first-tier results. Old statuses are labeled provisional and may not be reused as protocol outcomes. Lower tiers must be materialized from the source unit, or explicitly marked unavailable with a source-only reason. Search misses remain bounded, never fixed-corpus absence.
6. Repair exact exposure candidate detection with all 12-token windows at stride 1 over decoded JSON string values or decoded text files after Unicode and whitespace normalization. Record scanner version and matched file/span. This is candidate detection only; substantial-equivalence review still determines the ledger-v1 exposure state. Retain the fixed 347-file manifest and sealed KCC exclusion.
7. Preserve chronology-deviation metadata from all 18 affected plans. Such a plan has `primary_protocol_clean=false` forever; a clean plan repaired mechanically before gold may carry `IMPLEMENTATION_REPAIRED_BEFORE_GOLD`. New discretionary pairing rules cannot enter the primary set.
8. Re-screen the 45 provisional exclusions at their unchanged anchors under the actual panel semantic-family rule. Resolve the Panel B compound rule consistently even if that yields zero eligible Panel B cases. Record dependency clusters only after source and pairing identities are final.

The environment receipt records Poppler version, commands, encoding, OS/Python, PDF hashes, normalization, and raw-mode page hashes. A standalone audit package includes or hash-references the full frozen protocol, amendment, discovery procedure, and exposure ledger. No Qwen run, gold access, packet freeze, or historical-score rewrite belongs to CP2-R1.
