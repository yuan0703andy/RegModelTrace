# Proposal: RegModelTrace REVIEW-1

## Problem

The closed RegModelTrace release has immutable alignment, RAG, systems, and final-test artifacts, but it lacks one reconciled report that separates tasks, denominators, storage layers, and future research options. Historical summaries cannot substitute for identity-bound saved results.

## Change

Add a CPU-only, read-only reporting workflow that inventories immutable artifacts and storage, derives per-corpus v2.2 confusion matrices and class metrics, records which RAG metrics are computable, documents the current SQL/non-SQL architecture, assesses LoRA readiness without training, and designs a human-controlled sequential alignment audit.

## Boundaries

No inference, parsing, retrieval, adjudication, training, dependency upgrade, runtime switch, database mutation, vendor contact, or upload implementation is authorized. Test E and the technical release remain closed.
